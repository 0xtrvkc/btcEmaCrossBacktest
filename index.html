MVRV REGIME FILTER
—
Gate — blocks new entries beyond Reduce and queues exits at the Exit threshold.
Scale — sizes new entries between Reduce and Exit; existing BTC quantity stays fixed until exit. All orders fill at the next available close.
Availability — daily MVRV is delayed by the configured UTC calendar days and expires at the maximum age. The actual publication lag must be verified against the data source.
Interpretation — MVRV adds realized-cost information, but its market-value numerator also depends on price. Thresholds are research assumptions and are not calibrated automatically from BTC cycles.
RISK MANAGEMENT
%
ATR Trailing Stop — checked at each close with a stop that never loosens; exits fill at the next available close. A zero close-move estimate does not create a zero-distance stop. Recorded in the Trade Log with exit reason ATR Stop.
Vol-Targeted Sizing — reduces new-entry size (and the size carried by that trade going forward) during high-volatility regimes, and can increase it during calmer regimes while keeping the cash budget within 100%. It uses completed daily return volatility, with no future-day information.
Caution — both are mechanical overlays on top of the same limited BTC history as the rest of this backtest; validate out-of-sample before relying on either.

EMA ENTRY CASES
Each row applies the same option assumptions to a historical backtest entry.
#EMA SideOption OpenBTC RefStrikeCheckpointBTC RefDTE LeftCall Δ Open → RefPut Δ Open → RefΔUSD / +1% BTC at Open
Meaning — Δ estimates the option's USD-value change for a $1 move in BTC, per 1 BTC-equivalent option. Quantity scales it: ΔUSD ≈ Δ × BTC quantity × BTC price change.
Model — European Black–Scholes USD spot delta with zero yield and the global risk-free input. Long call Δ ranges from 0 to +1; long put Δ from −1 to 0. Short-option signs reverse.
Checkpoint — the EMA exit (or latest close for an open trade), capped at option expiry. If expiry arrives first, the row uses the BTC close at expiry and terminal delta.
Limits — constant user-entered IV, no volatility surface/skew, no historical option premium, and no exchange-recorded Greek. This is a risk lens only; it does not add an option trade, leverage, or naked exposure to the backtest.

METHODOLOGY
Data — validated BTC/USD close observations for the selected timeframe. Use Refresh to fetch again; the page does not stream prices. Timestamp labels are normalized to UTC. Gaps are flagged, not fabricated.
Signal and execution — SMA-seeded EMA periods count observed bars. A completed-close signal fills at the next available close, with configurable adverse slippage and per-fill fees. Live-aligned defaults to 0.05% fee plus 0.05% slippage per fill; presets never hide their inputs. Signals on the last bar remain unfilled. Backtests start in cash and wait for a new crossover.
MVRV — observations retain their source timestamp and receive the configured calendar-day delay. Values older than the maximum age are unavailable. Gate blocks entries; Scale changes new-entry size only. Missing observations block new entries and queue an exit of an open position. Publication lag is an explicit research assumption.
Sizing — all entry costs fit within the cash budget, capped at 100% after overlays. Uninvested cash earns 0%; the risk-free input is a Sharpe benchmark and option-model discount rate, not portfolio interest. Volatility sizing uses sample standard deviation of 14 completed daily returns and waits for that estimate to become available.
Options delta — historical EMA entries are repriced as hypothetical European options using standard Black–Scholes USD spot delta, the entry-date BTC close, strike percentage, DTE, constant IV, and risk-free input. The reference is the EMA exit/latest close capped at expiry. These are modeled sensitivities, not observed Deribit Greeks or option returns.
Shorts — fixed BTC quantity with linear USD P&L. Optional annual carry is integrated on prior-bar notional. This is not an exchange margin/liquidation simulation. If sampled portfolio value cannot cover closure, the model records a capital-exhaustion exit and stops trading; a price gap can leave a deficit.
Stops — the close-to-close Wilder proxy is not true OHLC ATR. The trailing stop only tightens, ignores a zero proxy, and queues a next-close exit. Intrabar stops cannot be reconstructed from close-only prices.
Returns — portfolio P&L includes both fees and all modeled costs. Calendar returns link to the previous period-end or initial capital; partial periods are marked. Mean Full-Year Return excludes partial years. CAGR uses exact elapsed time and requires 30 days, except a total loss is shown explicitly.
Risk statistics — Sharpe uses sample SD (N−1) and the configured risk-free rate. Sortino uses all N returns in the downside denominator. Both use complete, consecutive UTC daily intervals and √365.25 scaling; partial/gapped daily returns are excluded. Square-root scaling does not correct serial dependence or establish significance.
Drawdown — main drawdown uses every loaded bar and starts at initial capital. Rolling max drawdown retains the worst ordered peak-to-trough decline inside each window. Episode durations start at the prior peak; averages use recovered episodes. Ulcer Index uses available UTC day-end equity.
Filter impact — the comparison disables only MVRV and retains all other settings, costs and dates. The buy-and-hold benchmark buys at the initial available close and remains open; neither open strategy positions nor buy-and-hold are charged a hypothetical final exit fee.
Reproducibility — Run JSON records the versioned engine contract, public configuration, data-source hashes, metrics, costs, positions, trades, delta assumptions, and every historical delta case. Identical hashes identify identical fetched bytes.
Validation — the Validation tab performs a chronological fixed-rule split, a common-window EMA neighborhood, and execution-cost stress. Historical parameter/start-date selection can still overfit; these diagnostics do not establish a predictive edge or statistical significance.
